# 本地知识库同步

留序桌面版把知识库映射到一个真实文件夹。默认根目录是 macOS 的 `~/Documents/留序知识库` 或 Windows“文档”中的 `留序知识库`。可以在“设置 → 知识库”选择其他空目录；手机端只能使用已经由电脑配置的目录。

## 文件布局

- 每个知识库和子文件夹对应同名目录，空文件夹也会保留。
- 笔记是 UTF-8 Markdown。文件顶部的 front matter 保存 `liuxu_id`、标题、日期、标签、可见性和批注关系；正文编辑器不会显示这些字段。
- 笔记图片放在 Markdown 同目录，正文使用相对路径。笔记移动到另一个文件夹时会复制依赖图片并重写引用；删除一篇笔记不会自动删除可能被其他笔记引用的图片。
- PDF、DOCX、图片等档案保留原始二进制。留序提取的文本和预览信息仍放在 SQLite，避免改写原文件。档案批注是同目录的独立 Markdown。
- `.archive/` 保存已归档内容；`.liuxu/` 保存映射清单、操作日志、冲突草稿、删除回收和迁移记录，不会显示为普通知识条目。

文件名会替换 Windows 不允许的字符、结尾空格和保留名。大小写或同名冲突会自动添加编号。稳定文档 ID 用于识别外部改名和移动，因此不要手工复制同一份 front matter ID；若发生复制，留序会为副本分配新 ID。

## 同步规则

应用启动时会全量核对，运行中监听变化并定期补扫。留序保存采用同目录临时文件替换，并检查编辑器版本和上次读取的文件指纹。若外部程序先改了文件，留序不会覆盖磁盘内容：磁盘版本会进入正文，未保存输入保存在“设置 → 知识库 → 冲突草稿”。

外部新增普通 Markdown 无需 front matter，第一次同步时会自动补上稳定 ID。外部删除会移除留序条目；删除档案时也会移除关联批注。无法通过稳定 ID 可靠识别的二进制档案移动按删除和新增处理。

日记同样是本地明文 Markdown。留序仍会在界面、接口、Agent 和资源读取时执行日记锁定，但任何能直接读取电脑文件夹的本机用户或程序都能看到明文。把日记根目录放在受操作系统账户和磁盘加密保护的位置。

根目录断开、权限不足、符号链接或扫描失败时，同步会暂停并显示错误，不会据此批量删除数据库条目。“立即同步”可在排除问题后重新核对。

## 备份与恢复

工作区 ZIP 会包含 `knowledge-folder/` 下的便携文件树和 `.liuxu/manifest.json`，但不会保存本机绝对路径。跨设备恢复后，需要在新电脑选择知识库根目录。替换恢复到已启用同步的电脑时，留序先把当前文件树改名保存为带时间戳的恢复备份，再安装 ZIP 中的文件树。

旧 ZIP 仍可恢复。恢复完成后会清理派生搜索索引并重新构建；本地根目录配置属于机器设置，不随备份直接启用到另一台电脑。

## 离线迁移

仓库提供 `npm run knowledge:migrate-folder -- --data-dir <数据目录> --user-data <桌面配置目录> --root <空目标目录>`。迁移必须在留序完全退出且没有活动 Agent 任务时运行。工具会先：

1. 在目标根目录之外复制完整数据目录、桌面配置和本机密钥。
2. 校验 SQLite 完整性、逐文件 SHA-256 和隔离恢复副本。
3. 先检查旧图片引用；网络图片保持原网址，缺失的本地图片会写入备份目录的 `migration-preflight-report.json` 并阻止切换。随后在暂存目录生成全部笔记、档案、批注和图片并核对数量与哈希。
4. 最后切换根目录配置；失败时恢复原数据目录，并撤回本次安装的知识库目录。

旧数据目录和迁移备份不会自动删除。迁移报告分别写入备份目录和知识库根目录的 `.liuxu/migration-report.json`。
