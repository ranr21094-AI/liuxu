# 手机远程访问

留序桌面版可以通过 Tailscale Serve 向同一私有网络中的手机提供 HTTPS 页面。数据库、Agent、文件和脚本仍在电脑上运行；电脑必须保持开机联网，留序也必须继续运行。

## 开启与配对

1. 在电脑和手机从 [Tailscale 下载页](https://tailscale.com/download)安装客户端，并登录同一个 tailnet。
2. 在留序电脑端打开“设置 → 远程访问”，开启手机访问。默认本地端口是 `43140`；冲突时可改为其他 1024–65535 端口。
3. 点击“配置 Tailscale Serve”。留序只会在没有现有 Serve 配置时执行配置，且不会启用 Funnel。检测到已有配置时，会保留它并提示人工调整。
4. 生成一次性二维码，用手机扫描，在手机上填写设备名称，再回到电脑批准。

配对码 10 分钟内有效且只能使用一次。设备会话有效 30 天，可单独撤销；关闭远程访问会立即撤销全部会话并关闭监听入口。替换恢复工作区也会撤销已有远程会话。

## 手机使用范围

手机网页复用笔记、待办、Memory、主 Agent 和笔记助手。文件与脚本工具在电脑上执行，写操作仍进入逐项审批。手机不能修改目录白名单或远程授权设置。

首版不转播电脑屏幕、Chrome 扩展或笔记内置浏览器。手机发起的 run 会持久记录远程能力边界，其子任务也继承该边界，因此不提供 `browser.*` 和 `note_browser.*`。手机可以查看电脑发起任务的状态；若任务正等待桌面浏览器，应回电脑继续。

日记解锁 Cookie 与已授权设备绑定。手机断线或锁屏不会取消电脑上的任务；重新打开后，现有 SSE、审批和提问流程会按持久化 run 恢复。双端同时编辑仍使用文档版本号检查，冲突时保留手机草稿。

## 安全边界

- 远程监听只绑定 `127.0.0.1`，由 Tailscale Serve 终止 HTTPS；不直接监听局域网或公网地址。
- 远程入口对业务 API、附件和事件流统一要求设备会话。配对页和静态应用外壳可在登录前读取。
- 会话 Cookie 使用 `Secure`、`HttpOnly` 和 `SameSite=Strict`；所有远程写请求同时校验同源 `Origin` 和 CSRF Cookie/Header。
- 服务端只保存会话密钥哈希。远程授权保存在数据目录的 `.remote-access.json`，不进入工作区备份。
- Tailscale 的 tailnet 访问规则仍是到达服务前的第一层限制。参见 [Tailscale Serve 官方说明](https://tailscale.com/docs/features/tailscale-serve)。

关闭窗口后，如果远程访问已开启，桌面进程会留在后台继续服务。使用“设置 → 远程访问 → 完全退出留序”可停止本地与远程入口。电脑睡眠或应用退出后无法访问。
