# 本地文件工作区

文件模式将正文、导入原件和目录结构交给单个本地根目录。文档打开直接读取原文件，保存通过同目录临时文件替换原文件。SQLite 保存搜索缓存、历史和应用数据；缓存不能用来恢复运行期间缺失的原文件。

## 启用与迁移

现有数据仍默认运行旧模式。先保存编辑器草稿、结束 Agent 运行，再使用桌面「文件工作区」迁移入口，或完全退出应用后运行：

```sh
npm run knowledge:migrate-files -- --data-dir /absolute/app-data --root /absolute/notes --preflight
npm run knowledge:migrate-files -- --data-dir /absolute/app-data --root /absolute/notes --backup /absolute/independent-backup
```

迁移允许已有非空目录。应用数据、根目录和备份目录必须互相独立。预检列出缺失文件、数据库与磁盘内容差异及路径错误；正式执行先创建并校验完整备份，备份失败不切换模式。磁盘正文优先，数据库差异另存 `.liuxu/recovery/`；缺失文件恢复到空闲路径。旧 ID、历史与关联保持，旧副本保留。进度存于应用数据 `.file-workspace-migration.json`，中断后用相同根目录继续。

应用数据 `.knowledge-file-workspace.json` 启用文件服务。根目录 `.liuxu/storage.json` 标识可移植格式；`.knowledge-folder.json` 继续记录本机目录配置。完成迁移后换根目录尚未提供在线流程，应先备份并离线迁移，不要直接编辑标记。

回退前先另存迁移后新增和修改的文件，退出应用，用迁移前的完整数据库、文件树与配置备份恢复。不要只删除模式标记：旧数据库正文可能落后于磁盘。

## 文件与身份

根目录可以直接存文件，也可以有真实子文件夹。新 Markdown 不注入 front matter；已有 front matter、未知字段、BOM 与换行形式在正文保存时保留。标题覆盖写入旁路记录，文件重命名是单独操作；没有标题覆盖时显示文件名。

`.liuxu/documents/` 的每个记录有安全 UUID 文件名，保存稳定 ID、相对路径、标签、日期、角色与关系。应用内移动保持 ID；外部移动优先匹配文件身份，只有唯一明确的候选才按指纹匹配。相同内容的不同路径保持独立。删除进入 `.liuxu/trash/`，归档进入 `.archive/`。操作日志用于恢复中断的文件操作。

## 保存、冲突与接口

读取返回 `relativePath`、`baseFingerprint`、`indexState`、`storageMode: "files"` 和 `version`。修改、历史恢复、归档、还原、删除与重命名提交原读取的 `baseVersion` 和 `baseFingerprint`；缺失返回 400，过期返回 409。Agent 审批继续使用批准前的原始基准，不能用重新读取自动替换。

冲突保留编辑器草稿，允许查看磁盘内容后重新保存，不自动合并。保存期间新增输入继续排队。正文已替换后索引失败不会回滚文件，返回待更新状态，后台核对重试。旁路写入失败保留操作日志，重启恢复。不同程序同时修改同一路径仍存在最终检查与替换之间的竞争窗口，文件系统没有跨进程条件替换保证。

新增接口：`POST /api/knowledge/documents/:id/rename`（`filename` 和原始基准）、`POST /api/knowledge/index/rebuild`。现有同步接口在文件模式表示目录核对和索引状态；重建索引不清除历史、会话、Memory 或待办。

文件事件用于增量核对，周期完整扫描补漏；扫描未完整成功不会批量推断删除。读取仍检查磁盘，不依赖通知是否已到达。符号链接、根目录越界与超限文件被拒绝。

## 备份

新 ZIP 包包含原文件树、旁路记录和应用数据库。导出暂停文件服务写入，校验复制状态、文件哈希和完整目录清单；外部变化导致导出失败，请稍后重试。替换恢复保留原树备份，合并恢复使用新的导入目录和文档 ID，重写包内稳定链接、批注关系与历史。恢复文件保留为恢复材料，旧操作日志不作为当前任务运行。旧 JSON/ZIP 经兼容转换进入文件服务。

## 验证和当前边界

回归测试覆盖即时外部读取、原始基准冲突、两客户端竞争、保存后索引失败、元数据恢复、移动/归档/删除、批注联动恢复、目录断开、相同内容文件、换行/front matter、旧数据迁移与 ZIP 替换/合并。性能脚本 `npm run perf:files` 使用隔离临时目录，`PERF_DOCS=10000` 测万条数据，输出首次发现、完整核对、打开/保存/搜索 P50/P95、事件循环延迟及内存。

仍需完成跨平台发布验收：Windows 的真实文件监听、路径大小写与原子替换；打包后 Worker；其他编辑器复杂交互。隔离 Electron 实测已通过根目录展示、直接编辑、自动保存、重命名、文件名标题回退和外部修改即时读取。文件模式的格式提取及大型原件哈希在后台 Worker 执行，索引按最新版本排队，保存无需等待索引。首次发现万条文件需要建立身份和索引，会比稳定状态下打开/保存慢；本地热缓存性能数据不能代表冷盘或网络盘，也不是稳定性承诺。
