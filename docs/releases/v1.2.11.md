# 留序 LiuXu v1.2.11

本版本修复 ZIP 恢复覆盖当前库、Agent 与笔记助手互相串模型，以及 `ask_user` 问答从对话里消失等问题。

## 备份与恢复

- ZIP「合并」不再用备份库整库覆盖当前 `schedule.db`。知识笔记按文档 id 合并，较新的 `updatedAt` 获胜。
- 没有 `schedule.db` 的旧 ZIP 合并时只写入知识文档 JSON，不会删掉当前库。
- 「替换」先把备份库解到临时文件并做完整性校验，通过后再切换；切换后打不开则从恢复前备份滚回。
- 恢复完成后会丢掉已关闭的 Agent 连接，后续请求重新打开当前库。

## 日记与会话隔离

- 日记锁定时，不能用 runId 重放笔记助手事件，也不能删除该文档的助手会话。
- 笔记助手发消息时尊重所选会话；会话不属于当前文档则拒绝。

## Agent 运行时

- Agent 与笔记助手各自绑定本轮模型客户端，并发运行不再串用。
- 会话 checkpoint 保存完整对话，不再只留最后 40 条。
- `ask_user` 的提问和补充回答留在对话里，显示为「Agent 提问 / 补充回答」卡片，不再当成新任务气泡。
- 回答 `ask_user` 后不再重复画出同一条助手回复。
- Agent / 笔记助手输入框聚焦时不再出现内框虚线。

## 桌面更新

- 「检查更新」的 15 秒超时现在会真正生效。

## 发布文件

- Windows x64：`LiuXu-Setup-1.2.11-x64.exe` 及 `.sha256`
- macOS 12+ Apple Silicon：`LiuXu-1.2.11-mac-arm64.dmg`、`LiuXu-1.2.11-mac-arm64.zip` 及对应 `.sha256`
- `desktop-build-summary.json` 与 `desktop-build-summary-mac.json`

本次发布为测试包：macOS 使用 ad-hoc 签名，Windows 未使用 Authenticode 签名，尚未进行 Apple 公证。下载后请先根据 Release 页面提供的校验文件核对 SHA-256；首次打开可能需要在系统安全提示中确认。

任意 v1.2.0 及以上版本都可以在应用内直接更新到 v1.2.11，无需按顺序安装中间版本；应用内更新会识别本版本对应的平台安装包。
