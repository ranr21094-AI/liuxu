# 留序 LiuXu v1.4.2-1

## 知识库同步与图片修复

此修订版本修复 v1.4.2 的两项知识库问题：

- 知识库 Markdown 中的同目录相对图片会通过受权限保护的资源接口读取；预览过滤器现在允许安全的同源图片地址，并拒绝路径越界。
- 若数据库中有笔记但尚未建立本地文件映射，下一次同步会补写 Markdown 文件。旧笔记中的 HTML 上传图片会复制到笔记目录并转换为相对路径。
- 更新器识别 `1.4.2-1` 数字修订版本，可以从 `1.4.2` 检查并下载本版安装包。

本轮先发布 macOS Apple Silicon 包，最低支持 macOS 12。Windows 安装包仍使用 v1.4.2，后续单独构建发布。
