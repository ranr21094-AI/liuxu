# 留序 LiuXu v1.2.5

本版本聚焦 AI 助手侧栏的体验增强：会话切换器与多提案批量应用。全量 309 项自动化测试通过，浏览器以本地 mock 模型完成端到端验证。

## AI 助手会话切换器

- 侧栏头部新增「历史」按钮：下拉列出当前笔记/文件的全部 AI 会话（首条消息摘要、消息数、时间），当前会话高亮。
- 点击任一会话即可切换：消息替换为该会话内容，进行中的运行自动重新接入；切换时断开旧事件流，服务端运行不受影响。
- 每个会话可删除（原生确认框确认），会话的运行记录一并清理；删除当前会话后回到新对话状态。有活动运行的会话删除会返回 409 并提示先停止。
- 新增端点：`GET /api/agent/note-assist/:documentId/sessions`（轻量摘要）、`DELETE .../sessions/:sessionId`；`GET .../session` 支持按 `sessionId` 回读指定会话。

## 多提案批量应用

- AI 一次回复提出多条修改提案时，消息区上方出现批量条：「N 条提案待应用 [全部应用] [全部忽略]」，随提案到达与处理实时更新。
- 「全部应用」按提案到达顺序逐条套用：每条仍保留 find 唯一匹配校验，某条因前面的应用导致原文变化而失配时，单独跳过并标记，不阻塞其余；结束后汇总提示应用结果。
- 「全部忽略」批量置忽略；单条卡片的「应用 / 忽略」操作保持不变。

## 发布文件

- Windows x64：`LiuXu-Setup-1.2.5-x64.exe` 及 `.sha256`
- macOS 12+ Apple Silicon：`LiuXu-1.2.5-mac-arm64.dmg`、`LiuXu-1.2.5-mac-arm64.zip` 及对应 `.sha256`
- `desktop-build-summary.json` 与 `desktop-build-summary-mac.json`

本次发布为测试包：macOS 使用 ad-hoc 签名，Windows 未使用 Authenticode 签名，尚未进行 Apple 公证。下载后请先根据 Release 页面提供的校验文件核对 SHA-256；首次打开可能需要在系统安全提示中确认。

任意 v1.2.0 及以上版本都可以在应用内直接更新到 v1.2.5，无需按顺序安装中间版本；应用内更新会识别本版本对应的平台安装包。
