# 留序 LiuXu v1.2.0

## 补充构建：统一生图供应商

本次在不更改 `1.2.0` 版本号的前提下，将 Seedream 与 Getoken 生图流程统一为可扩展的供应商与模型配置。

- “设置 → 生图”支持添加 Seedream 或 OpenAI Images 兼容供应商。
- 每个供应商可配置 API 根地址、一个 API Key 和多个自定义模型。
- 模型能力与默认参数可单独调整，并可设置默认模型。
- OpenAI Images 兼容端点可尝试获取模型目录；也始终允许手动添加模型。
- 连接测试不会自动产生生图费用；“试生图”会在再次确认后生成一张图片。
- Agent 会根据参考图、多图、透明背景和图层拆分等需求选择兼容模型。

旧 Seedream 配置会自动转换为 Seedream 供应商卡；旧 Getoken 模型按相同 Key 合并，不同 Key 自动拆分。环境变量仍只作为只读 fallback，其值不会写入数据库。API Key 继续使用本机密钥加密，跨设备恢复无法解密时会安全清空并要求重新填写。

公网接口必须使用 HTTPS；HTTP 只允许本机或私网地址。不支持自由请求模板、任意请求头、响应表达式或加载第三方代码。正式生图仍由 Agent 审批工具执行，设置页只有在用户明确确认后才能试生图。

## 知识双链

知识文档现在支持稳定 ID 双链：

- `[[显示标题|note:123]]` 指向普通笔记。
- `[[显示标题|file:4]]` 指向导入文件或其可编辑批注。
- 在编辑器输入 `[[` 可搜索可访问的本地文档并用键盘选择。
- 手写 `[[标题]]` 在保存时只会自动解析唯一匹配；重名和未解析标题会保留原文并显示提示。

链接不会打开外部 URL。目标重命名不影响链接，归档目标显示归档状态，永久删除目标后显示断链。日记锁定期间，选择器、反向引用、片段和历史都按现有权限隐藏。

## 反向引用与历史

编辑器底部新增“反向引用 / 版本历史”面板。反向引用支持分页和点击定位；历史列表先返回元数据，选择版本后再加载正文并显示差异。每次内容或文档属性更新都会创建自动快照，5 分钟内合并，单篇最多 50 个版本且只保留最近 30 天。原始附件二进制不复制，但导入文件的提取正文和批注会进入历史。

恢复历史版本必须携带读取时的 `baseVersion`。恢复前会自动保存当前状态，若文档已被其他编辑更新则返回 409，不覆盖新内容。

## API 与备份兼容

新增：

- `GET /api/knowledge/link-targets`
- `GET /api/knowledge/documents/:id/backlinks`
- `GET /api/knowledge/documents/:id/revisions`
- `GET /api/knowledge/documents/:id/revisions/:revisionId`
- `POST /api/knowledge/documents/:id/revisions/:revisionId/restore`

新增 Agent 只读工具 `knowledge.backlinks`。REST API、SQLite 文档 JSON 和 ZIP 备份的现有字段保持兼容。完整 ZIP 替换恢复会保留历史；旧 JSON/ZIP 会在恢复后重建链接索引；结构 JSON 和合并恢复只迁移当前内容。
