# 留序 LiuXu v1.5.0

知识库档案新增本地电子书阅读器，直接打开“读书 / 我的书架”及其他文件夹中的书籍。支持 EPUB、MOBI、AZW3、FB2、TXT、PDF 和 CBZ，提供目录、搜索、续读、排版设置、专注模式、书签与摘录。摘录通过关联批注维护，并随备份恢复。

电子书阅读依赖本地提供，书内脚本和外部资源访问会被拦截。扫描 PDF 和漫画没有文字摘录入口。阅读进度与显示偏好留在本机；书签和划线随 JSON／ZIP 备份。
