# 留序 LiuXu v1.1.0

## 本次更新

- 重构设置 → 模型供应商卡片，能力覆盖保持展开，连接测试结果在对应模型内显示。
- 新增设置 → 更新：检查 GitHub Releases、下载当前平台安装包、校验 SHA-256 后打开安装程序。
- 更新服务运行在 Electron 主进程，渲染页面不能指定任意下载地址或本地文件。
- Windows x64 与 macOS Apple Silicon 构建摘要包含版本、架构、产物哈希和签名状态，不包含本机缓存路径。

## 安装包

- Windows 11 x64：`LiuXu-Setup-1.1.0-x64.exe`
- macOS 12+ Apple Silicon：`LiuXu-1.1.0-mac-arm64.dmg`、`LiuXu-1.1.0-mac-arm64.zip`

每个安装包均附带同名 `.sha256` 文件。首次安装请先核对哈希；测试包可能显示未知发布者或被 Gatekeeper 拦截。

## 应用内更新

`1.0.0` 用户需要先手动安装本版本。之后进入 **设置 → 更新** 即可检查后续标准版本（`vX.Y.Z`）。应用内更新不会迁移或覆盖工作区数据、API Key、备份和数据目录。

本版本只接受项目 GitHub Releases 的正式发布，不会执行源码 `git pull`。下载内容会在打开前校验 GitHub Asset SHA-256、配套 `.sha256` 与实际文件哈希。

## 已知限制

- 当前测试包未必具有 Developer ID / Authenticode 正式签名；应用会显示警告并要求再次确认。
- 应用内更新只支持 Windows x64 和 macOS arm64，ZIP 仍用于手动安装，不作为自动打开的更新包。
