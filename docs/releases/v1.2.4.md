# 留序 LiuXu v1.2.4

本版本包含两项主线更新：知识库每条笔记/文件的 AI 助手，以及模型设置与生图设置的界面优化。全量 306 项自动化测试通过，AI 助手链路经本地 mock 模型端到端验证。

## 知识库每条笔记/文件的 AI 助手

- 知识编辑器工具栏新增 AI 助手按钮：每条笔记和导入文件（PDF/DOCX/TXT 等）都有独立的对话式 AI 侧栏，针对本篇内容提问，也可检索并引用知识库中的其他笔记。
- AI 与主 Agent 共用运行时，但只开放只读工具（读取本篇、检索/阅读其他知识），不会执行写盘、命令或外部动作。
- 修改以「提案」交付：提案卡显示原文 → 改为的预览，点击「应用到笔记」后在编辑器中定位替换，走既有自动保存与版本历史；原文已被手动改动或出现多处匹配时拒绝应用并明确提示。服务端从不直接改写文档。
- 会话按文档持久化：重开笔记可回看历史对话；「新对话」开启全新会话；运行中可随时停止；重开时进行中的运行自动重新接入。
- 锁定的日记文档在解锁前不可使用助手；AI 未配置时给出明确提示。

## 模型设置 / 生图设置 UI 优化

- 生图设置从旧版折叠卡片迁移为与模型设置一致的「左列表 + 右详情」双栏工作区：侧栏显示供应商、协议、模型数与启用状态点，详情区内联编辑连接字段与模型能力。
- 连接测试与试生图结果改为在模型卡内定点更新，不再全量重绘清空正在输入的内容；模型设置的同路径问题一并修复；结构化重绘保留输入焦点、光标位置与滚动位置。
- 移除生图面板底部已废弃的旧版 Getoken/Seedream 隐藏表单及其加载/保存代码；已保存的旧字段值由服务端合并逻辑原样保留，旧配置仍会自动迁移为生图供应商。
- 视觉收束：新增 `--success` 主题变量（明暗双套），状态点、启用胶囊、测试结果、更新状态颜色统一改走主题 token；清理手风琴时代的死 CSS；修复生图设置中未定义的 `btn ghost` 按钮样式。

## 发布文件

- Windows x64：`LiuXu-Setup-1.2.4-x64.exe` 及 `.sha256`

本次发布为测试包：macOS 使用 ad-hoc 签名，Windows 未使用 Authenticode 签名，尚未进行 Apple 公证。下载后请先根据 Release 页面提供的校验文件核对 SHA-256；首次打开可能需要在系统安全提示中确认。

已安装 v1.2.3 的用户可以直接安装 v1.2.4；应用内更新会识别本版本对应的平台安装包。
