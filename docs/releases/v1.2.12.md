# 留序 LiuXu v1.2.12

本版本包含紧凑侧栏导航、知识库分类树修复及相关可访问性与回归测试。

## 界面

- 品牌栏收紧至 48px，`Agent｜知识库｜Memory｜待办` 改为单行等宽文字标签。
- 移除品牌栏折叠模块导航的旧行为，旧偏好不会再隐藏标签；整条侧栏的收起与 840px 以下抽屉保持不变。
- Memory 待确认数量改为右上角角标，最多显示 `9+`，按钮无障碍名称和提示保留完整数量。

## 知识库与分类

- 在已有文档路径下创建子分类时，自动补齐文档树中缺失的父级文件夹。
- 分类创建接口区分“分类已存在”和“父级分类不存在”，并保持原有状态码语义。

## 验证

- 全量测试：356 项，355 通过，0 失败，1 项 Windows 路径大小写测试在 macOS 上跳过。
- 已检查 1440×900、840×900、520×800 的浅色/深色主题；四标签单行且无横向溢出。

## 发布文件

- `LiuXu-Setup-1.2.12-x64.exe`（Windows x64，未签名测试包）
- `LiuXu-1.2.12-mac-arm64.dmg`、`LiuXu-1.2.12-mac-arm64.zip`（macOS Apple Silicon，ad-hoc 测试签名）
- 每个安装包对应 `.sha256`，并附 Mac/Windows 构建摘要。

首次打开测试包可能需要在系统安全提示中确认。发布前请根据 Release 页面提供的校验文件核对 SHA-256。v1.2.0 及以上版本可直接更新到 v1.2.12。
