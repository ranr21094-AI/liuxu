# 留序 LiuXu v1.2.2

## Agent 通用文件附件

- Agent 输入支持图片、Markdown、JSON、纯文本、常见代码、PDF 和 DOCX；可一次选择或拖拽多个文件。
- 文件默认由本地解析服务提取为当前会话上下文，不会自动创建知识笔记；长资料建议先导入知识库后按需检索。
- PDF 和 DOCX 复用知识库解析能力，扫描型 PDF 会明确提示需要 OCR；传统 `.doc` 上传时提示转换为 `.docx` 或 PDF。
- 附件卡片显示类型、大小、解析状态、截断提示和错误；图片保留缩略图与预览，其他类型显示文件图标。
- OpenAI Responses 的 `input_file` 与受支持的 Anthropic PDF 原生传输可按模型配置启用，其他协议安全回退到本地文本提取。

## 安全与兼容

- 服务端重新校验文件扩展名、MIME、文件头、路径、哈希、大小和私密日记权限；浏览器不能传入任意本地路径或 URL。
- 单文件与单条消息限制保持在安全范围内，旧的 `{url, filename}` 图片附件以及 `image` / `images` 上传字段继续兼容。
- 附件只保存在工作区 `uploads/` 并沿用 ZIP 工作区备份恢复，不新增数据库表或改变 REST/SQLite/备份格式。
- 模型设置继续使用稳定供应商 ID、模型级能力与文件传输选项，禁用供应商不会从配置中删除。

## 发布文件

- Windows x64：`LiuXu-Setup-1.2.2-x64.exe` 及 `.sha256`
- macOS 12+ Apple Silicon：`LiuXu-1.2.2-mac-arm64.dmg`、`LiuXu-1.2.2-mac-arm64.zip` 及对应 `.sha256`
- `desktop-build-summary.json` 与 `desktop-build-summary-mac.json`

本次发布为测试包：macOS 使用 ad-hoc 签名，Windows 未使用 Authenticode 签名，尚未进行 Apple 公证。下载后请先根据 Release 页面提供的校验文件核对 SHA-256；首次打开可能需要在系统安全提示中确认。

已安装 v1.2.1 的用户可以直接安装 v1.2.2；应用内更新会识别本版本对应的平台安装包。
