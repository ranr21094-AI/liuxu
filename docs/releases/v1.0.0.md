# 留序 LiuXu v1.0.0

这是留序 LiuXu 的首个公开 Windows 版本。

> 让重要信息留下，让下一步行动有序。

## 版本亮点

- 在一个本地工作台中使用 Agent、知识库、Memory 和待办。
- 数据默认保存在电脑本地，覆盖安装或卸载应用不会主动删除数据。
- 支持知识与工作区备份、恢复，以及在新电脑上整体迁移。
- Windows 客户端支持单实例启动、窗口恢复、安全的外部链接打开方式和启动故障日志。

## 安装方法

1. 下载 `LiuXu-Setup-1.0.0-x64.exe`。
2. 运行安装向导；安装目录可以在向导中修改。
3. 安装完成后，从桌面或开始菜单打开“留序 LiuXu”。

本版本尚未进行代码签名，Windows 可能显示“未知发布者”。请从本仓库 Release 页面下载，并使用一同提供的 `.sha256` 文件核对安装包完整性。

## 系统要求

- Windows 11 x64
- 建议保留至少 1 GB 可用磁盘空间
- AI 功能需要用户自行配置兼容模型供应商和 API 密钥

## 数据与升级

- 默认数据目录：`%LOCALAPPDATA%\Work Log Data`
- 兼容配置目录：`%APPDATA%\work-log`
- AI 密钥文件：`%LOCALAPPDATA%\work-log\ai-secrets.key`

上述旧名称为兼容已有 Work Log 安装和加密数据而保留。覆盖升级、卸载或重新安装均不会主动删除数据目录。换电脑时，请同时复制数据目录和 `ai-secrets.key`。

## 当前限制

- 仅提供 Windows 11 x64 安装包。
- 安装包未签名，暂不支持自动更新。
- 数据目录目前没有图形化选择器；可通过 `desktop-config.json` 或 `DATA_DIR` 配置。
- 模型请求会发送到用户配置的第三方供应商，使用前请确认其隐私政策。

安装、迁移、校验和故障排查的完整说明见项目 [README](../../README.md)。
