# 留序 LiuXu v1.4.3

## 修复内容

v1.4.3 将 v1.4.2-1 中先行发布于 macOS 的知识库修复统一带到 Windows 与 macOS：

- 修复知识库 Markdown 中同目录相对图片的显示，并校验资源路径，阻止路径越界。
- 同步时补写数据库中尚未映射到本地目录的笔记，避免条目只存在于应用内。
- 迁移旧笔记中的 HTML 图片引用时，把图片复制到 Markdown 同目录并改为相对路径。

更新器支持从 v1.4.2 和 v1.4.2-1 直接更新至本版。
