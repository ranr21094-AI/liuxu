# 留序 LiuXu v1.6.1

本次更新重点改善知识库层级切换、自动保存和编辑交互，并修复文件工作区、备份恢复与 Agent 任务续执行中的问题。

## 更新内容

- **知识库切换更快**：目录树直接读取结构元数据，文件夹列表使用专用索引，目录与列表并行加载；切换笔记复用侧栏节点，减少闪烁和重复请求。
- **编辑与保存更顺畅**：普通正文保存不再刷新整棵目录树，目录菜单按需生成；中文输入法组合结束后再安排保存与预览，未变化的预览不重复解析。
- **启动与扫描优化**：基础界面就绪与后台索引分开，无变化文件减少重复读取和哈希；超过 250 MiB 的文件单独跳过并显示提示，其他文件继续处理。
- **草稿与文件保护**：修复批注保存期间继续输入、切换文件时的草稿竞态；修复文件与目录并发移动的锁等待、索引重建后条目消失及默认数据库重开后的连接失效。
- **备份恢复修复**：旧格式 ZIP 替换恢复会正确清理文件模式标记，避免遗留同步状态覆盖恢复后的内容。
- **Agent 续执行修复**：子任务结束后恢复父任务审批队列；会暂停的浏览器工具依次执行，保留等待用户回复或重启后尚未执行的工具调用。
- **兼容与安全修复**：加强本地浏览器请求的来源检查，补齐 Anthropic 图片请求字段，文件补丁按字面值保留美元符号。

## 性能验证

同一台 Apple Silicon Mac、隔离的万篇笔记测试中，P95 结果如下：

| 操作 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 目录树读取 | 685 ms | 14 ms |
| 精确文件夹列表 | 272 ms | 2.8 ms |
| 界面切换文件夹 | 1.52 s | 51 ms |
| 自动保存完成（含 800 ms 停笔等待） | 1.58–1.68 s | 0.85–0.86 s |

目录树、列表与界面切层分别采样 100 次；四个编辑场景合计采样 400 次输入和 100 次自动保存。以上为暖态、合成数据与输入测试，不代表所有设备或冷启动表现。完整方法与原始记录见[性能报告](https://github.com/ranr21094-AI/liuxu/blob/v1.6.1/docs/performance-knowledge-interaction-2026-10-16.md)。

**已知限制：**长笔记内容变化后的分栏预览仍会整篇渲染，测试中仍出现超过 50 ms 的主线程任务；本次没有完全消除该场景的短暂停顿。
