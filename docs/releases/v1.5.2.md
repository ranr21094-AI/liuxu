# 留序 LiuXu v1.5.2

本次更新集中改进知识库档案阅读、文档历史、待办分类和 Memory 编辑体验。

## 更新内容

- 阅读器工具栏收纳低频操作，改进页码跳转、阅读设置、书签与摘录编辑；CBZ 支持文件级 Markdown 批注，漫画文字划线仍不支持。
- 提取文本搜索与文档批注增加留白；批注支持编辑、分屏和预览。知识库目录提供返回上一级入口。
- 知识库支持命名版本、差异对比和恢复，并可编辑受支持的 UTF-8 文本原件；关联历史与文档移动流程同步优化。
- 待办系统分类固定置顶，自定义分类支持重命名；优化分类、优先级和重复选中样式及新建入口。
- Memory 事实与流程支持编辑；改善模型供应商、设置和侧栏交互。

## 安装说明

- macOS 12+ Apple Silicon：ad-hoc 签名测试包，未完成 Apple 公证。
- Windows 11 x64：未签名安装包，由 Apple Silicon macOS 交叉构建，未在 Windows 实机安装验证。
- 更新应用不会覆盖已有知识、记忆、待办和设置。安装前可在设置中导出备份。
