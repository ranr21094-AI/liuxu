# 留序 LiuXu v1.5.1

本次更新统一工作区的侧栏、搜索、日期选择和设置界面，改善桌面、窄屏及低高度窗口的使用体验。

## 更新内容

- 统一四个板块的底部搜索与操作入口；侧栏可完全收起，悬浮展开按钮可拖动。
- 知识库采用紧凑分区目录、同层目录下拉及统一创建／导入／筛选菜单，空白页采用中英文欢迎效果。
- Agent 优化欢迎页、输入区、消息和执行状态，新建会话入口移至侧栏搜索框右侧。
- Memory 支持侧栏选择与单条正文详情，分类和搜索组合过滤，保留系统记忆草稿保护与待确认提案。
- 待办与倒数日统一详情面板、目录和搜索；邮件提醒使用底部弹出配置面板。
- 共享日期选择器统一五处日期入口，保留原有表单校验和键盘操作。
- 设置统一轻量布局；文本模型与生图配置采用供应商目录和独立详情，保留原有密钥保护及统一保存流程。
- 全页面输入框和选中状态改为细边框、轻底色与柔和聚焦效果。

## 安装说明

- macOS 12+ Apple Silicon：ad-hoc 签名测试包，未完成 Apple 公证。
- Windows 11 x64：未签名安装包，由 Apple Silicon macOS 交叉构建，未在 Windows 实机安装验证。
- 更新应用不会覆盖已有知识、记忆、待办和设置。安装前可在设置中导出备份。
