# 留序 LiuXu v1.4.0

笔记内置浏览器侧栏随桌面版发布。笔记正文、浏览器和笔记助手可以在同一窗口中并行使用，网页状态按笔记保存。

## 笔记内置浏览器

- 使用 Electron `WebContentsView` 承载远程网页，提供多标签、地址栏、前进、后退、刷新、停止加载、外部打开和关闭。
- 浏览器侧栏默认宽度为 420px，可拖动或用键盘调整；宽窗口使用正文｜浏览器｜助手三列，中等窗口改为右侧上下布局，极窄窗口使用辅助区切换或覆盖显示。
- 每篇笔记独立保存标签地址、顺序和选中标签。网页切换、收起和切换笔记不会主动刷新；应用重启后按需恢复网页。内置浏览器使用独立的持久化 session，登录状态与外部 Chrome 分开。
- 远程页面不加载应用 preload，启用沙箱、上下文隔离和网络安全策略，不能访问 Node、应用 IPC、本地文件、Cookie 或浏览器存储工具。
- 日记锁定会立即隐藏网页并停止助手访问；删除笔记或替换工作区时会清理关联状态。

## 笔记助手接入

- 笔记助手及其单层子任务可使用 `note_browser.tabs`、`note_browser.open`、`note_browser.read`、`note_browser.screenshot`、`note_browser.navigate`、`note_browser.click`、`note_browser.type`、`note_browser.select`、`note_browser.scroll` 和 `note_browser.close`。
- 读取标签、正文和截图无需确认；打开、导航、点击、输入、选择、滚动和关闭沿用现有逐项审批。审批保留笔记、标签、网址和页面版本，目标失效时不会自动改操作其他网页。
- 网页截图按现有附件和日记权限保护，并作为视觉上下文回传给助手。网页内容始终作为外部资料处理，不能改变助手权限规则。
