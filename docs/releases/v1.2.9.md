# 留序 LiuXu v1.2.9

本版本把模式切换收到左侧导航，并把知识库里的「留序 LiuXu」助手做成可停靠、可浮动、窄屏覆盖的布局。桌面收起侧栏后只留顶栏同一颗按钮，不再叠一颗悬浮汉堡。

## 工作台外壳

- Agent / 知识库 / Memory / 待办改到左侧导航；顶栏压到 52px，只保留当前模式标题、路径和运行状态。
- 点品牌「留序 LiuXu」只收起模式导航，不收起整列侧栏（会话列表、知识树、页脚仍在）。
- 桌面侧栏用顶栏 `#sidebarToggle` 收起/展开；收起后不再出现悬浮 ☰。窄屏仍用「打开侧栏」打开抽屉。
- 保存后顶栏副标题写知识库/文件夹路径，不再重复文档标题。长标题在列表和输入框内省略，页面不横向撑破。

## 留序助手停靠

- 宽屏默认停靠在正文右侧（320–480px，编辑区至少 600px）；不够宽或 `≤840` 时改为覆盖层，不改你保存的停靠偏好。
- 切到 Agent / Memory / 待办时，已打开的助手临时变成浮动窗；回到知识库后恢复停靠。
- 仍可手动切到浮动窗口（可拖动、缩放），位置与尺寸保存在本机。

## 密度与知识操作

- 知识侧栏搜索、Agent 会话工具条和相关主按钮改为 36px；`≤840` 文档左右内边距 24px。
- 窄屏顶栏运行状态保持可见。归档/删除收入文档「更多」菜单；知识筛选以可清除 chips 显示。
- Agent 对话列在宽屏固定 960px。

## 发布文件

- Windows x64：`LiuXu-Setup-1.2.9-x64.exe` 及 `.sha256`
- macOS 12+ Apple Silicon：`LiuXu-1.2.9-mac-arm64.dmg`、`LiuXu-1.2.9-mac-arm64.zip` 及对应 `.sha256`
- `desktop-build-summary.json` 与 `desktop-build-summary-mac.json`

本次发布为测试包：macOS 使用 ad-hoc 签名，Windows 未使用 Authenticode 签名，尚未进行 Apple 公证。下载后请先根据 Release 页面提供的校验文件核对 SHA-256；首次打开可能需要在系统安全提示中确认。

任意 v1.2.0 及以上版本都可以在应用内直接更新到 v1.2.9，无需按顺序安装中间版本；应用内更新会识别本版本对应的平台安装包。
