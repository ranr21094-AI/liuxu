# 留序 LiuXu v1.2.7

本版本是对 v1.2.3 之后新增代码与遗漏问题的第四轮系统复审：日记图片锁、`web.fetch` 跳转校验、Agent 审批状态机、设置保存一致性、知识笔记事务与循环待办均已修复。全量 322 项自动化测试中 321 项通过（1 项既有跳过）。

## 隐私

- 日记笔记内嵌图片上传会带上私密标记；`isPrivateUpload` 会扫描知识文档并回填 `private_uploads`，历史日记图即使没有旧标记也会受日记锁保护。
- 旧日志迁入知识库时，先落库再写迁移标记，并为日记日志中的图片补标，避免中途失败后日记图被当普通附件放出。

## 网络与供应商

- `web.fetch` 仍允许字面量 localhost / 私网（本机模型、局域网服务）；公网主机名不得 DNS 重绑定或重定向进私网，私网起点的跳转必须留在同一主机。
- 生图结果下载沿同一跳转校验；公网 HTTPS 供应商地址若解析到私网 IP 会被拒绝。

## Agent 稳定性

- 同一轮里 `ask_user` 与需确认工具并存时，确认项会排队而不是被用户输入状态吞掉。
- 同一审批项并发点两次只会执行一次；连续工具失败改为暂停等你补充说明，而不是停在空审批队列。
- 工具预算耗尽时只截断超出的调用，不再整批失败。
- 高级 Agent 限制补齐上限：保存时拒绝超限值，已存过大值会被夹紧。

## 设置与界面

- 未填完的已保存供应商卡片会阻止保存并提示，空白新建卡仍可跳过。
- 供应商连接测试不再重绘正在编辑的另一张卡；取消勾选会从目录里移除模型；删除供应商/模型需确认。
- 更换生图协议或根地址时保留已填 API Key。
- 模型/生图供应商侧栏去掉拖动手柄，启用改为开关，支持复制供应商；选择框宽度对齐。

## 知识与待办

- 创建笔记与保存导入文件的编号分配与写入在同一事务内完成。
- 把日记外的历史版本恢复到日记外时，可见性会降为普通笔记；恢复进日记则保持锁定。
- 无到期日的循环待办完成时以当天为基准生成下一次；HTTP / Agent 创建循环待办时必须带到期日。
- JSON 备份恢复可 round-trip 嵌套分类对象树。
- 自动保存会同时比对标题、标签、路径、日期和正文；Ctrl+S 刷新失败会提示。

## 发布文件

- Windows x64：`LiuXu-Setup-1.2.7-x64.exe` 及 `.sha256`
- macOS 12+ Apple Silicon：`LiuXu-1.2.7-mac-arm64.dmg`、`LiuXu-1.2.7-mac-arm64.zip` 及对应 `.sha256`
- `desktop-build-summary.json` 与 `desktop-build-summary-mac.json`

本次发布为测试包：macOS 使用 ad-hoc 签名，Windows 未使用 Authenticode 签名，尚未进行 Apple 公证。下载后请先根据 Release 页面提供的校验文件核对 SHA-256；首次打开可能需要在系统安全提示中确认。

任意 v1.2.0 及以上版本都可以在应用内直接更新到 v1.2.7，无需按顺序安装中间版本；应用内更新会识别本版本对应的平台安装包。
