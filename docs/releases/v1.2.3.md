# 留序 LiuXu v1.2.3

本版本是对此前两轮代码审查后新增代码与历史遗漏的第三轮系统复审，共修复 30 项问题；全部修复通过 302 项自动化测试（含 9 项新增针对性用例）。

## 严重修复

- 修复浏览器工具结果提交路由缺少 `await` 的问题：此前未知运行的提交会错误返回成功，且模型调用抛错时可能直接终止整个服务进程。
- 修复 `bash.run` 超时后命令在 macOS/Linux 继续后台运行的问题（进程组未分离导致超时杀进程无效），并给 `code.run` 的进程组终止增加兜底信号。

## 数据与隐私

- 修复 Windows 旧数据迁移遗漏生图供应商密钥重加密的问题：此前配置过生图 Key 的用户迁移后 AI 设置将无法解密；迁移收尾现在会做"解密回读"自检，失败即中止迁移，旧目录不受影响。旧 `.env` 自定义过数据目录的用户迁移也不再误判加密 scope。
- 收紧日记锁不变量：把普通分类重命名/移动到"日记"路径下的文档会自动锁定，移出日记路径也不会静默解锁；修复日记锁经分类重命名被绕过的问题。
- 导入的 SVG 文件改为强制下载打开，不再以应用同源身份内联渲染，杜绝同源 XSS 面。
- 知识笔记创建收紧附件注记的父类型校验，删除笔记时级联清理注记，不再留下孤儿数据。

## Agent 稳定性

- 修复 Agent 运行内存泄漏：运行记录在进入终态后从内存清除。
- 修复取消运行的竞态：模型调用或工具执行期间点击取消，本轮待执行工具不会再运行，已取消的运行不会再被审批队列"复活"；对已完成的运行调用取消不再改写状态。
- Agent 运行历史的 200 条保留策略不再淘汰仍在等待审批或用户输入的运行。
- 修复委派子任务转发用户回复时丢失附件的问题。
- 修复"重复创建/删除"守卫中创建-删除交替循环检测永不生效的死代码。
- 恢复前"活动运行拦截"改查 SQLite 数据，此前该检查因读取旧版 JSON 文件而形同虚设。
- 旧版 AI 对话迁移改为直接写入 SQLite：此前写入的 JSON 文件无人读取，导致迁移"成功"但对话不可见（原始数据仍保留在备份文件中，升级后重新打开 Agent 页会自动迁移）。

## 备份与恢复

- ZIP 恢复的体积限额不再信任 ZIP 声明值：改为流式解压并计量实际字节，伪造头部无法再绕过限额耗尽内存。
- 恢复替换 SQLite 数据库改为临时文件 + 原子改名，并清理旧 WAL/SHM 残留；数据库关闭失败时中止恢复而不是继续覆盖。

## 界面与体验

- 修复知识文档自动保存竞态：保存请求在途时继续输入不再弹出"文档已在其他位置修改"的伪冲突，也不会静默丢失最新输入。
- 修复生图供应商设置页在连接测试/试生图后保存会静默清空已输入 API Key 的问题。
- docx 预览在安全组件未加载时显示占位提示，不再注入未消毒内容。
- 待办组件补齐输出转义与失败提示。

## 安全加固

- Chrome 扩展命令执行路径新增可选签名校验：在"设置 → 电脑"完成配对后，把密钥保存到扩展弹窗，扩展此后只执行带本应用签名的浏览器命令；未配置密钥时保持原行为。结果回传签名校验改为常数时间比较，外部消息入口收窄到配对命令与只读标签页扫描。
- 生成图片地址校验识别十六进制 IPv4-mapped IPv6 的内网形式（如 `::ffff:c0a8:101`）。
- 知识导入：PDF 解析加 500 页上限，导入解析加并发上限；知识索引变更表按已持久化版本裁剪，不再无限增长。
- 应用内更新：检查请求加 15 秒超时，下载防重复触发；扩展结果回传 nonce 集合加上限。
- 知识文档路径字段与正文增加显式长度上限（正文超过 500k 字符返回明确错误）。

## 构建与工程

- 构建脚本复制 vendor 资产前先清理旧目录，避免历史文件被打包分发。
- Windows 交叉构建对 win32 预编译 SQLite 模块增加内嵌 SQLite 版本与本机 better-sqlite3 的交叉校验，并记录到构建摘要。
