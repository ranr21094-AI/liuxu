# 留序 LiuXu v1.2.10

本版本把 Agent、笔记助手和 Memory 刷新的静态系统提示词放进 Memory，可在界面里编辑并恢复默认；笔记助手会话不再混进 Agent 历史；并修正自定义供应商对笔记助手的 400 错误。

## Memory 系统提示词

- Memory 侧栏增加「系统」筛选，内置三条：Agent 系统提示词、笔记助手系统提示词、Memory 刷新指令。首次启动只播种缺失项，不会覆盖你已经改过的正文。
- 保存和「恢复默认」都要连续确认两次（继续 → 应用）。系统条目不能删除；正文上限 8000 字，空内容不能保存。
- 运行时只读取 Memory 里的静态正文。L0 安全规则、工具列表、工作检查点、媒体/附件提示、`@` 注入和 Kimi Formula 仍由代码拼接，不会随 Memory 改写。
- Agent 的 `memory.list` / `memory.search` / `memory.read` / `memory.propose` 看不到、也不能改这些系统条目。

## 笔记助手隔离与 400 修复

- 绑定了文档的笔记助手会话不再出现在 Agent 侧栏、会话 CRUD 和 Memory 刷新扫描里；笔记助手自己的接口不变，ZIP 工作区仍会导出全部会话。
- 笔记助手发给自定义供应商的 system 改为单段文本，不再把字符串数组直接塞进 `messages[0]`，避免 `invalid type: string` 的 400。

## 品牌折叠指示

- 「留序 LiuXu」旁改为 12px 描边 chevron：导航展开朝下，收起朝右。

## 发布文件

- Windows x64：`LiuXu-Setup-1.2.10-x64.exe` 及 `.sha256`
- macOS 12+ Apple Silicon：`LiuXu-1.2.10-mac-arm64.dmg`、`LiuXu-1.2.10-mac-arm64.zip` 及对应 `.sha256`
- `desktop-build-summary.json` 与 `desktop-build-summary-mac.json`

本次发布为测试包：macOS 使用 ad-hoc 签名，Windows 未使用 Authenticode 签名，尚未进行 Apple 公证。下载后请先根据 Release 页面提供的校验文件核对 SHA-256；首次打开可能需要在系统安全提示中确认。

任意 v1.2.0 及以上版本都可以在应用内直接更新到 v1.2.10，无需按顺序安装中间版本；应用内更新会识别本版本对应的平台安装包。
