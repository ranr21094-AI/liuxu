# 留序 LiuXu v1.4.1

## 手机远程访问

v1.4.1 在 Windows/macOS 桌面版加入 Tailscale 私有网络访问。电脑端开启“设置 → 远程访问”后，留序使用独立的 `127.0.0.1:43140` 入口，由 Tailscale Serve 提供 HTTPS；本地窗口入口、数据库和 Agent 运行时保持共用。

- 一次性二维码配对，10 分钟过期且只能使用一次；电脑批准后建立 30 天设备会话。
- 支持设备单独撤销、全部退出和完全退出留序；替换工作区会撤销远程会话。
- 远程业务 API、附件和 SSE 使用安全 Cookie、同源校验和 CSRF 防护。
- 手机可编辑笔记、管理待办、使用 Memory、Agent、笔记助手、联网、生图、文件和脚本工具；文件和脚本在电脑上执行。
- 手机发起的任务和子任务不提供 `browser.*`、`note_browser.*`；日记解锁按设备会话隔离，断线后任务继续运行。

详细配置步骤见[手机远程访问说明](../remote-access.md)。
