# 留序 LiuXu v1.3.0

笔记助手升级为完整 Agent，并修复自动保存、备份恢复、搜索、浏览器验签和子任务续答等 9 项审查问题。

## 完整笔记助手

- 使用与主 Agent 相同的工具与运行预算，独立初始化联网、图片、电脑与浏览器能力。
- 支持审批队列、提问续答、记忆提案、图片和单层子任务；重新打开会话可继续待处理交互。
- 确认后直接修改当前笔记：先保存草稿，检查原始版本号，执行期间锁定编辑，完成后刷新；冲突需重新读取并确认。
- 保留预览修改提案、目录白名单、日记权限和用户自定义提示词。

## 数据可靠性

- 自动保存等待正在进行的请求与后续编辑，失败或冲突时保留输入并阻止切换。
- 旧 ZIP 恢复不再依赖目标目录残留 JSON；SQLite ZIP 不再受冗余 JSON 的 10 MiB 解析限制阻断。
- 导出与恢复采用一致限额；恢复中途失败回滚，替换后重建搜索索引。
- 文件批注及图片跟随父文件的私密权限；待办、倒数日与分类写入失败不再提示成功或清空表单。
- 修复扩展验签编码，无需重新配对；修复子任务回答后重复调用与重复完成。
- 包含会话布局与宽度调整。

## 验证

379 项测试：378 通过、0 失败、1 项 Windows 平台测试在 macOS 跳过；包含模拟 HTTP/SSE 与编辑器交互回归。Windows 安装包由 macOS 交叉构建，未进行 Windows 实机安装测试。

## 下载与升级

- Windows x64：`LiuXu-Setup-1.3.0-x64.exe` 及 `.sha256`
- macOS 12+ Apple Silicon：`LiuXu-1.3.0-mac-arm64.dmg`、`LiuXu-1.3.0-mac-arm64.zip` 及对应 `.sha256`
- `desktop-build-summary.json` 与 `desktop-build-summary-mac.json`

沿用现有测试包签名方式：Windows 未使用 Authenticode 签名；macOS 使用 ad-hoc 签名，尚未经过 Apple 公证。请核对 SHA-256；首次打开可能需要在系统安全提示中确认。

v1.2.0 及以上版本可在应用内直接更新到 v1.3.0，无需安装中间版本。
