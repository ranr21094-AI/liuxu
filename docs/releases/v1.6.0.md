# 留序 LiuXu v1.6.0

本次更新引入可迁移启用的本地文件工作区，并让阅读数据和文件工作区保持一致。

## 更新内容

- 知识库文件模式直接读取和保存本地文件；SQLite 用于搜索与索引，`.liuxu/` 保存文档身份和旁路元数据。外部修改会触发冲突保护，索引失败不会撤销已经落盘的正文。
- 桌面新增迁移预检、备份及可续跑迁移。现有用户不会在升级后自动切换；迁移前应结束 Agent 任务、保存草稿并检查报告。数据库中与磁盘不同的正文会作为恢复副本保留。
- ZIP 备份和恢复包含文件树、旁路记录及应用数据库；替换和合并按稳定文档 ID 保持历史、批注、阅读位置和书籍关联。
- 阅读位置与阅读时间独立持久保存；浏览器旧位置可迁入数据库。书签与摘录保存在旁路记录中，阅读器增加本次和累计阅读计时及暂停恢复。
- 批注编辑区明确区分摘录和个人笔记；源文件变化或定位失效时保留摘录并显示状态，不静默覆盖。
- 文件索引、搜索与迁移流程增加冲突和恢复回归覆盖，文件工作区大文件解析移入后台任务。

## 安装说明

- macOS 12+ Apple Silicon：ad-hoc 签名测试包，未完成 Apple 公证。首次打开如被 Gatekeeper 拦截，请在“系统设置 → 隐私与安全性”中确认“仍要打开”。
- Windows 11 x64：未签名交叉构建包，未在 Windows 实机安装验证。首次运行可能显示未知发布者提示。
- 迁移会修改知识库文件和应用存储。升级前先在应用中导出备份；迁移请先运行预检并确认备份完成。
