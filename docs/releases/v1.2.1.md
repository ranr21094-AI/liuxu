# 留序 LiuXu v1.2.1

## 模型配置界面

- 设置 → 模型改为左侧供应商导航、右侧详情编辑的双栏布局。
- 供应商支持启用/禁用、删除和快速切换；当前供应商的名称、Base URL、API 格式和 API Key 集中展示。
- 模型列表支持添加、删除、能力覆盖和连接测试；测试状态及错误详情显示在对应模型下方。
- 切换供应商、编辑能力或拉取模型列表时会保留当前未保存草稿。
- 禁用供应商会从 Agent 模型选择器中隐藏，内部供应商 ID、重复条目和无效模型不会直接展示。

## 兼容性与安全

本版本保留现有 REST API、SQLite 数据和备份格式。API Key 继续使用本机密钥加密保存；更新模型设置时，留空 API Key 会在供应商身份未改变时复用已保存密钥。禁用供应商不会删除其配置，重新启用即可恢复使用。

## 发布文件

- Windows x64：`LiuXu-Setup-1.2.1-x64.exe` 及 `.sha256`
- macOS 12+ Apple Silicon：`LiuXu-1.2.1-mac-arm64.dmg`、`LiuXu-1.2.1-mac-arm64.zip` 及对应 `.sha256`
- `desktop-build-summary.json` 与 `desktop-build-summary-mac.json`

本次发布为测试包：macOS 使用 ad-hoc 签名，Windows 未使用 Authenticode 签名，尚未进行 Apple 公证。下载后请先根据 Release 页面提供的校验文件核对 SHA-256；首次打开可能需要在系统安全提示中确认。

已安装 v1.2.0 的用户可以直接安装 v1.2.1；应用内更新检查也会识别本版本对应的平台安装包。
