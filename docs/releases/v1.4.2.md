# 留序 LiuXu v1.4.2

## 本地文件夹知识库

v1.4.2 在 Windows 和 macOS 桌面版加入知识库与本地文件夹双向同步。首次安装后进入“设置 → 知识库 → 选择文件夹”，选择默认的“文稿/留序知识库”或其他目录即可启用；已有知识条目会迁移到所选目录。留序内的编辑和整理会写入文件夹，外部增删改与移动会同步回留序。

- Markdown 文件以 UTF-8 保存，front matter 保留稳定文档 ID、标题、日期、标签和可见性；知识库与子文件夹对应本地目录。
- 图片与引用它的 Markdown 放在同一文件夹，使用相对路径；PDF、Word 和图片档案保留原始文件，批注单独保存为 Markdown。
- 同时编辑时以本地文件为准；留序不会覆盖外部修改，未保存草稿可从设置中的“冲突草稿”恢复。
- 同步使用原子写入、版本与文件指纹检查，并拒绝路径越界和符号链接逃逸。日记仍受留序权限保护。
- 工作区 ZIP 可携带便携的知识文件树；跨设备恢复后可选择新的本地根目录。离线迁移工具会先备份并校验，再切换数据库与文件树。

详细操作和故障恢复见[本地知识库同步说明](../knowledge-folder-sync.md)。
