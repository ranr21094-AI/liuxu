# 留序 LiuXu v1.2.8

本版本把知识库里的 AI 助手做成可拖动的「留序 LiuXu」弹窗，并把笔记标题栏压成一行，编辑区给正文留出更多空间。

## 留序 LiuXu 弹窗

- 笔记和导入文件工具栏按钮打开的助手更名为「留序 LiuXu」，从侧栏改为浮动窗口：可拖动、可从右下角缩放，位置与尺寸保存在本机。
- 切换到 Agent、Memory 或待办时，已打开的留序窗口不会自动关掉。
- 输入区对齐 Agent 作曲栏（多行输入、附件、发送），模型选择与顶栏全局模型一致。
- 新会话默认标题为「留序 LiuXu」。

## 知识库导航

- 从知识库切到其他模式再返回时，会回到刚才打开的笔记；若当时在浏览某个知识库/文件夹，也会回到该位置。

## 紧凑笔记标题栏

- 标题、保存状态、属性 chips 与编辑/分屏/预览及操作图标排成一行。
- 标题输入改为圆角字段；「已保存」改为标题旁的淡色文字，保存中/失败仍用警告与危险色。
- 属性 chips 只显示实际值：知识库始终出现，文件夹不是根目录才显示，日期和标签有值才显示；不再写「无日期 · 无标签」。
- 点 chips 展开原有四列表单（知识库、文件夹、日期、标签）；折叠时不再占一整条灰底。

## 发布文件

- Windows x64：`LiuXu-Setup-1.2.8-x64.exe` 及 `.sha256`
- macOS 12+ Apple Silicon：`LiuXu-1.2.8-mac-arm64.dmg`、`LiuXu-1.2.8-mac-arm64.zip` 及对应 `.sha256`
- `desktop-build-summary.json` 与 `desktop-build-summary-mac.json`

本次发布为测试包：macOS 使用 ad-hoc 签名，Windows 未使用 Authenticode 签名，尚未进行 Apple 公证。下载后请先根据 Release 页面提供的校验文件核对 SHA-256；首次打开可能需要在系统安全提示中确认。

任意 v1.2.0 及以上版本都可以在应用内直接更新到 v1.2.8，无需按顺序安装中间版本；应用内更新会识别本版本对应的平台安装包。
