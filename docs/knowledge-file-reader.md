# 知识库文件阅读器

导入档案后，留序在正文区域显示预览。顶部可以切换 **预览、批注、提取文本**；助手和浏览器侧栏仍可同时使用。批注单独保存为关联 Markdown，预览和文字提取不会改写原始文件。桌面版还提供下载与系统打开，网页版提供下载。

## 格式支持

| 类型 | 阅读方式 | 说明 |
| --- | --- | --- |
| PDF | 按需渲染页面、跳页、缩放、旋转、搜索和选择文字 | 扫描件会提示缺少可搜索文字；本版不做 OCR。 |
| Word `.docx` | 浏览器内分页预览 | 图片、表格、页眉页脚和列表由本地渲染库处理；内容运行在无脚本、无网络访问的沙箱内。 |
| Excel `.xlsx`、`.xls`、`.ods` | 工作表选择、行列编号、搜索、单元格查看与复制 | 数字和日期使用已有单元格格式；公式只显示文件中保存的计算结果。大表格按可视行渲染。 |
| CSV、TSV | 表格预览、搜索、编码和分隔符选择 | 支持带引号的字段、字段内换行、UTF-8、UTF-16 与 GB18030；文本内容按字符串处理，保留前导零和长数字。 |
| PowerPoint `.pptx` | 幻灯片列表、缩放和延迟加载 | 显示文字、图片和常见图形；复杂动画和效果可能与 PowerPoint 不同，不播放动画。 |
| 图片 | 适应窗口、放大缩小、原始尺寸、拖动和旋转 | 支持 PNG、JPEG、GIF、WebP、BMP、AVIF 和 SVG；SVG 通过受限图片响应读取，不作为应用页面执行。 |
| 文本与代码 | 行号、搜索和自动换行 | 支持 TXT、LOG、JSON、XML、YAML、HTML、CSS、JavaScript/TypeScript、Python、Shell、SQL 等。HTML 和脚本按文本展示。 |
| 音视频 | 浏览器原生播放器 | 支持 MP3、WAV、M4A、OGG、FLAC、MP4、WebM 和 MOV；编码不受支持时可下载或在桌面系统应用中打开。 |
| ZIP | 只读目录、名称搜索和分页 | 不解压，也不打开压缩包内文件。拒绝加密条目、越界路径和符号链接条目。 |

旧版 `.doc`、`.ppt`、RAR、7z、TIFF 和 HEIC 暂不内嵌渲染，仍可下载或在桌面版使用系统应用打开。Markdown 笔记继续使用原来的 Markdown 编辑器。

## 文件和预算

知识库单文件导入、本地同步和备份附件共用 250 MiB 上限。上传先写入临时文件，指纹校验和附件复制以流式或文件级操作完成；请求范围读取支持 PDF、音视频等大文件按需加载。

内嵌解析预算低于单文件上限。DOCX、表格、PPTX 和 CSV/文本超过 30 MiB 时保留原文件并显示预览受限提示；PDF 使用分段读取，音视频直接由播放器请求数据。Office 压缩文档在解析前校验容器结构，条目不超过 20,000 个、展开总量不超过 512 MiB、单条目不超过 128 MiB。搜索文字仍按各格式的文本提取上限截取。损坏、加密、超限或无法解码时，原文件和批注仍可用。

备份 ZIP 压缩大小上限为 2 GiB、总展开大小为 4 GiB、数据库为 120 MiB、条目为 20,000 个，单个附件为 250 MiB。导出写入磁盘临时文件后流式传输；上传恢复也先暂存、校验，再安装。旧 JSON 备份的单份 JSON 仍限制为 10 MiB；含有效 SQLite 的 ZIP 以数据库为准，冗余兼容 JSON 不会阻止替换或合并恢复。

## 实现结构

- `lib/knowledge/file-formats.js` 是后端识别、MIME 映射和文件上限的统一注册表；导入、同步及读取使用同一分类规则。
- `lib/knowledge/import.js` 提取检索文本并验证 Office 压缩容器；`lib/knowledge/routes.js` 提供权限受控的 Range 内容、预览元信息和 ZIP 目录接口。
- `public/js/knowledge/filePreview.js` 管理每份预览的取消与清理，PDF 页面按需渲染；本地 UI 依赖（PDF.js、docx-preview、JSZip、SheetJS、PPTX renderer）由 `scripts/build-editor.mjs` 固定复制到 `public/vendor/`，无需 CDN。
- `lib/workspace/zip.js` 使用磁盘暂存和流式 ZIP 读写；恢复前校验路径、实际解压字节数、SQLite 完整性和附件哈希，并在安装失败时回滚。
