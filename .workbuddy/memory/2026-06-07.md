## WeStock Bug Fixes
1. **spawn npx ENOENT**: `childProcess.spawn` was using `shell: false`, but on Windows `npx` is a `.cmd` script. Fixed by setting `shell: true` in `server.js` line 761.
2. **命令 "quote" 在当前渠道不可用**: The `quote` command doesn't exist in the `westock-data-clawhub` CLI. Removed `quote` from `WESTOCK_ALLOWED_TOOLS` and `WESTOCK_SYMBOL_TOOLS`, added missing tools (`lhb`, `blocktrade`, `margintrade`, `buyback`, `etf-company`, `etf-holders`, `etf-financial`). Updated AI prompt to remove `quote` and add new tools. Updated tests from `quote` to `kline`. All 46 tests pass.
3. **WeStock request timed out**: `kline --limit 30` takes ~29s but timeout was only 20s. Increased `WESTOCK_TIMEOUT_MS` from 20000 to 60000 (60s).
