搜索范围

电脑

开启后，Agent 可在白名单目录里读写或删除文件，并运行 Python（code.run）或 Bash 命令（bash.run：git / npm / node 等，需确认）；Windows 也支持 PowerShell。脚本与 Bash 命令在第一个白名单目录（或指定 cwd）下执行。

目录白名单
只允许已存在的目录。敏感路径（如 .ssh）无法加入。
扩展配对（推荐）
配对成功后把显示的密钥粘贴到扩展弹窗保存；此后扩展只执行带本应用签名的浏览器命令。

备份与恢复

JSON 备份仅含结构数据（分类、待办、倒计时等，不含知识附件）；ZIP 工作区包含笔记、附件与 Agent 数据。恢复含日记的数据前请先解锁日记。
